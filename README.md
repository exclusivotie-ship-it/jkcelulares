Plataforma de comércio eletrónico completa desenvolvida com React 19, TypeScript, Tailwind CSS, Supabase (PostgreSQL) e preparada para Cloudflare Pages.

## Funcionalidades Principais
- **WhatsApp Commerce:** Fluxo de compra instantâneo e finalização de carrinho com mensagens oficiais pré-formatadas.
- **Catálogo de Tecnologia:** Smartphones, iPhones, Samsung, Xiaomi, Portáteis, Desktops, Monitores, Acessórios e Gadgets com preços em Kwanzas (Kz).
- **Sistema de Afiliados Avançado:** Links individuais com código de referência (`?ref=...`), rastreamento de cliques, janela de atribuição de 30 dias e comissões automáticas.
- **GladIA:** Assistente inteligente para consultoria de eletrónicos e recomendação de produtos por orçamento em Kz.
- **Painel Administrativo Completo:** Gestão de produtos, encomendas, stock, clientes, afiliados, CRM comercial, fornecedores, finanças e configurações.
- **Exportação em ZIP:** Gerador integrado na aplicação para download do pacote completo personalizado com manuais e SQL.
